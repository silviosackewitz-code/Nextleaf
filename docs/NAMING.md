# Naming research

Historical snapshot: 2026-10-17. These findings are not current availability or
legal clearance. The owner chose to retain **Nextleaf** after discussing overlaps.
Nextlief was a typo. No domain purchase was authorized or performed.

## Nextleaf

Existing software uses include [Supergamer1337/NextLeaf](https://github.com/Supergamer1337/NextLeaf)
(a self-hosted reading project associated with Hardcover/Grimmory) and
[NeonCipher01/NextLeaf](https://github.com/NeonCipher01/NextLeaf) (a Gradio-based AI
book project). The [nextleaf GitHub organization](https://github.com/nextleaf) exists.
A repository-name search returned six results, not all exact product-name matches.
No indexed App Store result in the search was not proof of absence.

| Domain | Result on the research date |
| --- | --- |
| nextleaf.com | Registered; [Verisign RDAP](https://rdap.verisign.com/com/v1/domain/nextleaf.com) |
| nextleaf.org | Registered; [RDAP](https://rdap.org/domain/nextleaf.org) |
| nextleaf.app | RDAP 404; [Google Registry](https://pubapi.registry.google/rdap/domain/nextleaf.app) |
| nextleaf.dev | RDAP 404; [Google Registry](https://pubapi.registry.google/rdap/domain/nextleaf.dev) |

RDAP 404 does not guarantee a name is purchasable or safe to use.
[Nextleaf Solutions](https://www.nextleafsolutions.com/) is an existing cannabis
business. The [Canadian trademark journal of January 23, 2019](https://www.ic.gc.ca/opic-cipo/tmj/eng/23Jan2019_en.pdf?edition=01-23&year=2019)
contains filing 1859452. [Justia](https://trademarks.justia.com/876/22/nextleaf-87622769.html)
reports US application 87622769 / registration 5991615, class 40; current official
status was not verified. The [USPTO record interface](https://tsdr.uspto.gov/#caseNumber=87622769&caseSearchType=US_APPLICATION&caseType=DEFAULT&searchType=statusSearch)
was a reference, not completed clearance. Relevant goods/services and jurisdictions
matter; [DPMA research](https://www.dpma.de/marken/markenrecherche/) and
[classification](https://www.dpma.de/marken/klassifikation/) were background references.

## Rejected or unchosen alternatives

Clear Trail was rejected after software/IT overlaps were found:
[ClearTrail Technologies](https://www.linkedin.com/company/cleartrail-technologies/),
[ClearTrail Managed IT](https://cleartrail-it.co.uk/), and
[adukhan98/cleartrail](https://github.com/adukhan98/cleartrail), a compliance project.
The GitHub account exists, and .com/.org/.app were registered. The direct
clear-trail.com request returned 403; that did not imply absence.

Donebrook and Readyfern were researched but not chosen. Exact GitHub account
queries returned 404, repository-name searches returned zero, and .com/.app RDAP
queries returned 404 on the research date. Donebrook appeared in a historical
[New York military archive](https://museum.dmna.ny.gov/download_file/view/6201);
Readyfern had an OCR-like historical occurrence, not an identified software product.
These observations were preliminary, not registrations or full legal checks.

Nextglade/Taskglade were rejected as too close to
[Nextclade](https://github.com/nextstrain/nextclade) and
[Taskade](https://help.taskade.com/en/articles/8958642-what-is-taskade).
Other candidates had existing uses: [Tasklume](https://tasklume.llc/),
[Leafward](https://www.leafward.de/en/collections/all),
[Calmfolio](https://calmfolio.app/), and [Leafstride](https://github.com/asuna-mt).
